# Changelog

All user-relevant changes are documented in this file.

## [2026.9.0] - 2026-09-17

### Added

- Added automatic discovery and persistent lifecycle tracking for installed HACS repositories.
- Added an administrator-only panel with summaries, search, filters, sorting, ratings, statuses, notes, tags, usages, and review history.
- Added manual and scheduled synchronization that preserves historical records when repositories are removed or reinstalled.
- Added a configurable review interval and calculated review states.
